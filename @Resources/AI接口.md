# FatFishNote · AI 接口说明

> 面向程序 / AI 的对接契约，不是给普通用户看的。
> 版本：v1.6 ｜ 适用皮肤：FatFishNote

---

## 0. 一句话规则

**只往 `@Resources\ai_drop.txt` 投递；不要直接改 `notes.txt`。**

皮肤是唯一的写入方。绕过它直接改数据文件，会被运行中的皮肤覆盖。

---

## 1. 投递格式

文件：`<皮肤目录>\@Resources\ai_drop.txt`

- 编码：**GBK（代码页 936）**
- 换行：CRLF 或 LF 均可
- 每行一条便签，字段用 **制表符（`\t`）** 分隔：

```
YYYY-MM-DD<TAB>名称<TAB>正文
```

- `#` 开头的行是注释，会被忽略
- 名称为空 → 自动生成默认名
- 一行只能有一条，**正文里不能出现换行或制表符**

示例：

```
# 这一行是注释
2026-10-28	待办	列出今天要做的事
2026-10-28	复盘	今天哪件事顺、哪件别扭
2026-10-29	复查	确认上周的账对完了
```

---

## 2. 生效时序

- 皮肤每 **4.8 秒** 轮询一次 `ai_drop.txt`
- 导入后**文件会被清空** —— 文件变空 = 已被接收
- 也可以主动触发（立即导入）：

```
!CommandMeasure NoteLua "aiTick()"
```

> 皮肤启动后约 8 秒内不要投递：这期间数据还没加载完，导入会被门禁挡掉。

---

## 3. 边界与规则

| 项 | 规则 |
|---|---|
| 日期窗口 | `[今天 - 4 天, 今天 + 1 天]`，超出**静默丢弃** |
| 上限 | 全部便签最多 **30 条**，超出部分丢弃 |
| 去重 | **同名 + 同日期视为同一条**：更新正文，不新增 |
| 来源标记 | 导入的便签 `src=ai` |
| 失败表现 | 不写盘、不清空文件；错误进 `Rainmeter.log` |

批量投递建议：一次不超过 10 条，间隔 ≥ 6 秒，否则可能被 30 条上限截断。

---

## 4. 读回状态

直接读 `@Resources\notes.txt`（GBK，只读，不要写）：

```
#FatFishNote v3
#grid cols=2 rows=4 scale=1.00
#theme 1
#page 0
2026-10-28	待办	列出今天要做的事	ai	1
2026-10-28	固定示例	钉在常驻区的便签	user	1	1
```

字段顺序：

| 序 | 字段 | 说明 |
|---|---|---|
| 1 | 日期 | `YYYY-MM-DD` |
| 2 | 名称 | 卡片标题 |
| 3 | 正文 | 卡片内容 |
| 4 | 来源 | `user` / `auto` / `ai` |
| 5 | 主题 | 1–4，对应四种配色 |
| 6 | 固定 | 可选，`1` = 固定在常驻区 |

---

## 5. 可调用的接口

| 调用 | 作用 |
|---|---|
| `!CommandMeasure NoteLua "aiTick()"` | 立即导入 `ai_drop.txt` |
| `!CommandMeasure NoteLua "reloadNotes()"` | 重新读 `notes.txt`（外部改过之后） |
| `!CommandMeasure NoteLua "autoWrite('modes=monthly;dday=1;dname=交周报;dtext=整理进度')"` | 改自动便签规则（白名单键） |
| `!CommandMeasure NoteLua "autoDump()"` | 把当前自动规则打到日志 |
| `!CommandMeasure NoteLua "favCount()"` | 收藏库条数 |
| `!CommandMeasure NoteLua "quickOpen('today')"` | 打开快记输入框（今天） |
| `!CommandMeasure NoteLua "quickOpen('pin')"` | 打开快记输入框（常驻区） |

---

## 6. 禁止事项

| 禁止 | 原因 |
|---|---|
| 直接写 `notes.txt` | 运行中的皮肤会覆盖；写坏会导致便签清空（有拒写保护，但不是绝对安全） |
| 用 UTF-8 写 `ai_drop.txt` | 皮肤按 GBK 读，会变成乱码或不匹配 |
| 正文里塞换行/制表符 | 会破坏行格式，整行被丢弃 |
| 投递超过日期窗口的便签 | 静默丢弃，不报错 |
| 一次性投 20 条以上 | 会撞 30 条上限 |

---

## 7. 排错

日志位置：`%APPDATA%\Rainmeter\Rainmeter.log`

| 关键字 | 含义 |
|---|---|
| `导入 AI 便签 N 条，更新 M 条` | 成功（N 新增 / M 覆盖） |
| `拒写：内存 X 条 < 磁盘 Y 条` | 写盘保护触发，说明数据被保护性拦下 |
| `COMPACT N` | 自愈压缩过一次数组空洞，属正常 |
| `Script: File not valid` | 脚本加载失败（不是语法问题就是 local 超限） |

**投了没反应**，按这个顺序查：

1. 日期是否在窗口内
2. 文件编码是否 GBK
3. 制表符是否真的存在（不是空格）
4. 皮肤是否刚重启（8 秒门禁）
5. 日志里有没有 `导入 AI 便签`
