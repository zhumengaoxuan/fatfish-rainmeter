# FatFishNote · 肥鱼便签

> 一张贴在桌面上的便签板：按日期分列、随手记、自动生成周期任务，重要的固定到常驻区，暂时不用的收进收藏库。

- 作者：肥鱼
- 版本：v1.6
- 环境：Rainmeter 5.0 及以上（需要 `TextEdit` 米特）/ Windows 10 及以上

---

## 一、它是什么

FatFishNote 是一块常驻桌面的便签板。每一天是一列，便签是列里的卡片，可以直接写字、拖动、换色、删除。

左侧是**常驻区**：拖进去的便签会固定住，不随日期翻页消失。
右上角的 **★** 打开**收藏库**，暂时不用的便签收进去，需要时再拖出来。

不联网（除了天气与番剧表），不上传，所有内容都是本地纯文本，随时可以备份和手改。

---

## 二、安装

1. 安装 [Rainmeter 5.0+](https://www.rainmeter.net/)
2. 双击 `FatFishNote_v1.6.rmskin`，按提示安装
3. 安装完成后便签板自动出现在桌面上

**手动安装**：把 `FatFishNote` 文件夹放进 `文档\Rainmeter\Skins\`，在 Rainmeter 管理器里加载 `FatFishNote\FatFishNote.ini`。

安装后是空的，按 `Ctrl+Alt+N` 随手记一条，或从「拖出新便签」框拖一张出来。

## 三、界面

```
┌──────────────────────────────────────────────────────┐
│  日历        FatFish便签 ★        时钟 / 天气 / 农历  │
│            ┌──────────────┐                          │
│            │  拖出新便签   │                          │
│            └──────────────┘                          │
├──────────┬─────────────────┬─────────────────────────┤
│  常驻区   │ ‹  今天 10/28   │   明天 10/29        ›    │
│ ┌──────┐ │ ┌─────────────┐ │ ┌─────────────┐         │
│ │ 便签 │ │ │ 便签     ×  │ │ │ 便签     ×  │         │
│ └──────┘ │ └─────────────┘ │ └─────────────┘         │
└──────────┴─────────────────┴─────────────────────────┘
```

- **★**：打开 / 关闭收藏库
- **‹ ›**：向前 / 向后翻页
- **拖出新便签**：拖入一张便签 = 收进收藏库
- **右下角小圆点**：拖动可缩放整块板子
- **常驻区右侧进度条**：固定便签超过可视行数时出现，点上半 / 下半翻页，滚轮一行

## 四、操作

### 便签

| 操作 | 效果 |
|---|---|
| 左键拖便签 | 移动（换日期、换位置） |
| 拖进常驻区 | 固定，不随日期消失 |
| 双击正文 | 编辑内容 |
| 双击标题 | 改名 |
| **单击标题条** | 循环切换配色（紫 → 蓝 → 绿 → 橙） |
| 点右上角 × | 删除 |
| 右键 → 换插图 | 给这张卡片挂一个角标（循环切换，第 13 次回到无图） |
| 右键 | 打开设置页 |

### 插图与角标

卡片可以挂一张小插图，有两种显示方式，用同一张图：

| 状态 | 显示 |
|---|---|
| 正文有内容 | 卡片右下角一张 **108px 大图**，压在正文下面 |
| 正文为空 / 只有「新便签」「(空)」 | 卡片中间一张 **88px 大图**，半透明水印感 |

- 换图：右键 →「换插图」，在 12 张里循环，转一圈回到无图
- 内置素材在 `@Resources\img\`（来源与许可见同目录 `NOTICE.txt`）
- 想加自己的图：把 PNG 放进 `@Resources\img\`，文件名用小写英文/数字/下划线

### 常驻区

| 操作 | 效果 |
|---|---|
| 把便签拖进来 | 按落点插入 |
| 拖出去 | 回到日期列 |
| 滚轮 | 上下滚动 |
| 进度条上 / 下半 | 翻一页 |

### 收藏库

| 操作 | 效果 |
|---|---|
| 点 ★ | 打开 / 关闭 |
| 点条目 | 恢复到今天 |
| 拖条目到格子 | 取消收藏，落到那一格 |
| 拖条目到「拖出新便签」 | 删除（会先写回收记录） |
| 右键条目 | 从收藏库删除 |

被删除的收藏会追加到 `favorites_deleted.txt`，手误还能捞回来。

### 热键快记

| 热键 | 效果 |
|---|---|
| `Ctrl + Alt + M` | 弹出输入框 → 回车 → **插到常驻区第一位** |
| `Ctrl + Alt + N` | 弹出输入框 → 回车 → **加到今天列末尾** |

- 输入框出现时会自动抢焦点，直接打字即可
- `Esc` 取消，`回车` 保存
- 同名入口也在右键菜单里：「快记到常驻区」「快记到今天」
- 输入期间整块皮肤会临时置顶，关闭后还原

> 热键是全局的：在任何窗口里按都有效。

## 五、自动便签

在 `settings\settings.ini` 里配置（右键便签可打开），支持四种模式：

| 模式 | 含义 |
|---|---|
| 间隔天数 | 每隔 N 天生成一条 |
| 每月第 X 日 | 每月固定某天生成 |
| 按月轮换 | 按当月日期在规则表里轮流取值 |
| 按日轮换 | 按日期偏移在规则表里轮流取值 |

规则写成「名字 / 正文」，可配多条。也可以用指令改：

```
!CommandMeasure NoteLua "autoWrite('modes=monthly;cycle=2;dday=1;dname=交周报;dtext=整理本周进度')"
!CommandMeasure NoteLua "autoDump()"
```

`autoWrite` 会先备份 `autonote.txt.bak` 再重写，写错键会被白名单挡掉。

## 六、番剧便签

每天首次刷新皮肤时，会抓一次当季番剧表，生成一张「今日番剧」便签（最多 4 条，超出显示「等 N 部」）。

- 数据源：`yuc.wiki`
- 抓取脚本：`@Resources\anime.ps1`，结果写到 `@Resources\anime.txt`
- 关闭：在 `autonote.txt` 里加一行 `anime=0`
- 手动刷新：右键菜单 →「刷新番剧」
- 抓取失败不影响已有数据，日志在 `anime.log`

## 七、数据文件

全部在 `Skins\FatFishNote\@Resources\` 下，纯文本（GBK），可备份、可手改：

| 文件 | 内容 |
|---|---|
| `notes.txt` | 所有便签（日期、标题、正文、来源、主题、是否固定、插图名） |
| `favorites.txt` | 收藏库 |
| `favorites_deleted.txt` | 删除回收记录 |
| `autonote.txt` | 自动便签规则 |
| `city.txt` | 天气城市 |
| `anime.txt` | 当日番剧缓存 |

另有 `AI接口.md`：给程序 / AI 的投递协议（怎么写 `ai_drop.txt`、有哪些可用指令）。

**改之前先备份**。想立刻生效可以执行：

```
!CommandMeasure NoteLua "reloadNotes()"
```

## 八、常见问题

**节气多天显示同一个名字，是 bug 吗？**
不是。节气是一个时刻，界面显示的是约 15 天的区间，插件返回「第 N 天」，界面上把后缀去掉了。

**热键没反应？**
可能被别的软件占用。换一个组合需要改 `FatFishNote.ini` 里的 `HotKey=`，改完刷新皮肤。

**按热键后输入框闪一下就没了？**
多半是前台没抢到。确认 `@Resources\focus.ps1` 存在；某些安全软件会拦进程抢前台。

**英文长串不换行？**
`ClipString` 只在空格处断行。皮肤会对纯 ASCII 的超长串自动插断点，中文本来就按字换行。

**天气一直是同一个城市？**
设置页里切换城市，内置几个预设（直接写经纬度，避免中文地理编码失败）。

**收藏库满了？**
上限 50 条，删掉不用的即可。

**便签会自己消失吗？**
超过 5 天的普通便签会被清理；固定在常驻区的不受影响。
