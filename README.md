# FatFishNote · 肥鱼便签

> 一张贴在桌面上的便签板：按日期分列、随手记、自动生成周期任务，还能把暂时不用的便签收进收藏库。

- 作者：肥鱼
- 版本：v1.5
- 环境：Rainmeter 5.0 及以上 / Windows 10 及以上

---

## 一、它是什么

FatFishNote 是一块常驻桌面的便签板。每一天是一列，便签是列里的卡片，你可以直接在上面写字、拖动、换色、删掉。

它不联网、不上传，所有内容都是本地纯文本，随时可以备份和手改。

**适合的场景**

- 每天要提醒自己的几件事（订货、对账、交周报）
- 有明确周期的重复任务（每月 1 号、每隔 N 天）
- 临时记一下、过段时间再翻出来的东西（进收藏库）

---

## 二、功能一览

| 模块 | 能力 |
|---|---|
| 便签 | 新建、编辑、改名、删除、复制、置顶/上移/下移 |
| 日期列 | 左右翻页看历史与未来；拖到空白处自动新增一列 |
| 配色 | 每张便签独立配色，四种主题，点色点即时切换 |
| 自动便签 | 四种生成规则，按日期自动补便签，可一键停用 |
| 收藏库 | 最多 50 条，拖出即恢复、拖进删除框即删除 |
| 右上角 | 时钟、天气、农历与节气信息，长文本自动跑马灯 |
| 数据 | 全部为本地文本文件，可直接编辑与备份 |

## 三、安装

1. 安装 [Rainmeter 5.0+](https://www.rainmeter.net/)（旧版本没有 `TextEdit`，无法输入）
2. 双击 `FatFishNote_v1.5.rmskin`，按提示安装
3. 安装完成后，便签板会自动出现在桌面上

**手动安装**：把 `FatFishNote` 文件夹放进 `文档\Rainmeter\Skins\`，再在 Rainmeter 管理器里加载 `FatFishNote\FatFishNote.ini`。

第一次启动会自动生成「今天」和「明天」两列，并按默认规则补一条自动便签。

## 五、操作

| 操作 | 效果 |
|---|---|
| 左键拖便签 | 移动（换日期、换位置） |
| 双击便签正文 | 编辑内容 |
| 双击便签标题 | 改名 |
| 右键便签 | 打开设置页 |
| 拖到「拖出新便签」框 | 收进收藏库 |
| 拖到列外空白 | 新增一列并落进去 |
| 点右上角 × | 删除这张便签 |

**收藏库**

| 操作 | 效果 |
|---|---|
| 点 ★ | 打开收藏库 |
| 点条目 | 恢复到今天 |
| 拖条目到某一格 | 取消收藏，落到那一格 |
| 拖条目到「拖出新便签」框 | 直接删除（会先写回收记录） |
| 右键条目 | 从收藏库删除 |
| 悬浮条目 | 出现四个色点，可改这条的配色 |

被删除的收藏会追加到 `favorites_deleted.txt`，手误还能捞回来。

## 六、自动便签

在 `settings\settings.ini`（右键便签可打开）里配置，支持四种模式：

| 模式 | 含义 |
|---|---|
| 间隔天数 | 每隔 N 天生成一条 |
| 每月第 X 日 | 每月固定某天生成 |
| 按月轮换 | 按当月日期在规则表里轮流取值 |
| 按日轮换 | 按日期偏移在规则表里轮流取值 |

规则写成「名字 / 正文」的形式，可以配置多条。

也可以用指令直接改：

```
!CommandMeasure NoteLua "autoWrite('modes=monthly;cycle=2;dday=1;dname=交周报;dtext=整理本周进度')"
!CommandMeasure NoteLua "autoDump()"
```

`autoWrite` 会先备份 `autonote.txt.bak` 再重写，写错键会被白名单挡掉。

## 七、数据文件

全部在 `Skins\FatFishNote\@Resources\` 下，纯文本，可备份、可手改：

| 文件 | 内容 |
|---|---|
| `notes.txt` | 所有便签（日期、标题、正文、来源、主题） |
| `favorites.txt` | 收藏库 |
| `favorites_deleted.txt` | 删除回收记录 |
| `autonote.txt` | 自动便签规则 |
| `city.txt` | 天气城市 |

**改之前先备份**：`notes.txt` 写坏会让便签板变空，但把备份改回名字就能恢复。

## 八、常见问题

**节气多天显示同一个名字，是 bug 吗？**
不是。节气是一个时刻，但显示成 15 天左右的区间，插件返回的其实是「第 N 天」，界面上把这段后缀去掉了。

**改了 `notes.txt` 但界面没变？**
皮肤在启动时读一次文件。改完在皮肤上做任意一次拖动/翻页触发重排，或执行 `!CommandMeasure NoteLua "reloadNotes()"`。

**窗口太窄，显示不下两列？**
右下角小圆点可以缩放；也可以把窗口拉宽，列数会跟着变。

**收藏库满了？**
上限 50 条。删掉不再需要的条目即可。

**天气一直是同一个城市？**
在设置页里切换城市，内置了几个预设城市（直接写经纬度，避免中文地理编码失败）。
